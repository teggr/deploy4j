Set these values to configure Spring Boot specific settings for your application containers.

They are used by the [Spring Boot Commands]({{ 'commands/spring-boot' | relative_url }})

```yaml
spring_boot:
    # Actuator port
    acutator_port: 8080
    # Actuator base path
    actuator_base_path: /actuator
```
